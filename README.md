# Boda Camila & Jorge · 06.11.2027 — versión 2

Web estática para GitHub Pages (rama `version-2`). La versión anterior sigue intacta en la rama `main`.

- `index.html` – contenido de la web
- `css/styles.css` – estilos y animaciones CSS
- `js/main.js` – sobre que se abre, cuenta atrás, animaciones de scroll, calendario, formulario
- `js/config.js` – fecha de la boda y URL del formulario (`rsvpEndpoint`)
- `js/guia.js` – listas de hoteles, restaurantes y planes (se rellenan aquí)
- `assets/img/` – dibujos de Camila (WebP con fondo transparente)
- `assets/og/og-image.jpg` – imagen que sale al compartir el enlace por WhatsApp

No necesita librerías externas: solo carga las fuentes de Google Fonts.
