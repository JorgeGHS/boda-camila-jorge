# Boda Camila & Jorge · 06.11.2027

Web estática para GitHub Pages.

- `index.html` – contenido de la web
- `css/styles.css` – estilos
- `js/config.js` – fecha de la boda y URL del formulario de asistencia (`rsvpEndpoint`)
- `js/main.js` – cuenta atrás, menú, avión, formulario y confeti
- `assets/img/` – ilustraciones de Camila (fondo transparente)

Publicar: subir a un repo nuevo → Settings → Pages → Deploy from branch `main` / root.
